SECTION – A (1 Mark each) [5 × 1 = 5]
1. Find the number of proper subsets of the set $\{p, q, r, s\}$.
Solution: Total subsets = $2^4 = 16$.
Proper subsets = total subsets − 1 (excluding the set itself) = $16 - 1 = 15$.
Answer: 15
2. If $\left(\frac{x}{2} + 1, \, y - \frac{1}{4}\right) = \left(\frac{3}{2}, \frac{3}{4}\right)$, find the values of $x$ and $y$.
Solution: Equating components:
$\frac{x}{2} + 1 = \frac{3}{2} \Rightarrow \frac{x}{2} = \frac{1}{2} \Rightarrow x = 1$.
$y - \frac{1}{4} = \frac{3}{4} \Rightarrow y = 1$.
Answer: $x = 1$, $y = 1$
3. Assertion & Reason based:

Assertion (A): $\cos x$ is positive in first and fourth quadrants.

Reason (R): $\tan x$ increases from $0$ to $\infty$ in first quadrant and increases from $0$ to $\infty$ in third quadrant.

a. Both A and R are true and R is the correct explanation of A. b. Both A and R are true but R is not the correct explanation of A. c. A is true but R is false. d. A is false but R is true.
Solution: Assertion (A) is true: $\cos x > 0$ in QI and QIV.
Reason (R) is also true: $\tan x$ increases from $0$ to $\infty$ in QI and from $0$ to $\infty$ in QIII.
However, R does not explain why $\cos x$ is positive. The sign of $\cos$ depends on the $x$-coordinate.
Answer: (b) Both A and R are true but R is not the correct explanation of A.
4. Find the value of $(i^{19})^{-4} + \frac{1}{i^{-13}}$.
Solution: $i^{19} = i^{16} \cdot i^3 = 1 \cdot (-i) = -i$.
$(i^{19})^{-4} = (-i)^{-4} = \frac{1}{(-i)^4} = \frac{1}{i^4} = \frac{1}{1} = 1$.
$i^{-13} = \frac{1}{i^{13}} = \frac{1}{i^{12} \cdot i} = \frac{1}{1 \cdot i} = \frac{1}{i} = -i$.
$\frac{1}{i^{-13}} = \frac{1}{-i} = i$.
Sum = $1 + i$.
Answer: $1 + i$
5. Write the range of the function $f(x) = \frac{|x|}{x}$, $x \neq 0$.
Solution: For $x > 0$, $|x| = x \Rightarrow f(x) = 1$.
For $x < 0$, $|x| = -x \Rightarrow f(x) = -1$.
Answer: Range = $\{-1, 1\}$
SECTION – B (2 Marks each) [6 × 2 = 12]
6. Let $A = \{2, 4, 6, 8, 10\}$, $B = \{1, 2, 3, 4, 5, 6\}$. Find $A - B$ and $B - A$.
Solution: $A - B = \{x \in A : x \notin B\} = \{8, 10\}$.
$B - A = \{x \in B : x \notin A\} = \{1, 3, 5\}$.
Answer: $A - B = \{8, 10\}$, $B - A = \{1, 3, 5\}$
7. Find the domain and range of the function $f(x) = \sqrt{49 - x^2}$.
Solution: Domain: $49 - x^2 \ge 0 \Rightarrow x^2 \le 49 \Rightarrow -7 \le x \le 7$.
Range: $0 \le \sqrt{49 - x^2} \le 7$.
Answer: Domain = $[-7, 7]$, Range = $[0, 7]$
8. A pendulum of length 60 cm swings and its tip describes an arc of 22 cm. Find the angle in radians.
Solution: Arc length $l = r\theta \Rightarrow \theta = \frac{l}{r} = \frac{22}{60} = \frac{11}{30}$ radians.
Answer: $\frac{11}{30}$ radians
9. If $(x + iy)(1 - 2i) = 3 - i$, find $x$ and $y$.
Solution: $(x + iy)(1 - 2i) = (x + 2y) + i(y - 2x) = 3 - i$.
Equating real and imaginary parts:
$x + 2y = 3$ ...(1)
$y - 2x = -1$ ...(2)
From (2): $y = 2x - 1$.
Substitute in (1): $x + 2(2x - 1) = 3 \Rightarrow 5x - 2 = 3 \Rightarrow x = 1$.
Then $y = 2(1) - 1 = 1$.
Answer: $x = 1$, $y = 1$
10. Find the range of the function $f(x) = \frac{|x - 7|}{x - 7}$.
Solution: For $x > 7$, $|x - 7| = x - 7 \Rightarrow f(x) = 1$.
For $x < 7$, $|x - 7| = -(x - 7) \Rightarrow f(x) = -1$.
Answer: Range = $\{-1, 1\}$
11. If $\tan \theta = \frac{3}{4}$ and $\theta$ lies in third quadrant, find $\sin \theta$ and $\cos \theta$.
Solution: In QIII, both $\sin$ and $\cos$ are negative.
$\tan \theta = \frac{3}{4} = \frac{\text{opposite}}{\text{adjacent}}$.
Hypotenuse = $\sqrt{3^2 + 4^2} = 5$.
$\sin \theta = -\frac{3}{5}$, $\cos \theta = -\frac{4}{5}$.
Answer: $\sin \theta = -\frac{3}{5}$, $\cos \theta = -\frac{4}{5}$
SECTION – C (3 Marks each) [5 × 3 = 15]
12. Let $A$, $B$, $C$ be sets such that $A \cup B = A \cup C$ and $A \cap B = A \cap C$. Show that $B = C$.
Solution: Let $x \in B$. Then $x \in A \cup B = A \cup C$, so $x \in A$ or $x \in C$.
If $x \notin C$, then $x \in A$. So $x \in A \cap B = A \cap C$, hence $x \in C$, contradiction.
Thus $x \in C$, so $B \subseteq C$.
Similarly, $C \subseteq B$. Therefore, $B = C$.
Answer: Hence proved.
13. If $\sin x = -\frac{5}{13}$ and $\pi < x < \frac{3\pi}{2}$, find the values of $\sin \frac{x}{2}$, $\cos \frac{x}{2}$ and $\tan \frac{x}{2}$.
Solution: $\cos x = -\sqrt{1 - \sin^2 x} = -\sqrt{1 - \frac{25}{169}} = -\frac{12}{13}$ (QIII).
$\frac{\pi}{2} < \frac{x}{2} < \frac{3\pi}{4}$, so $\sin \frac{x}{2} > 0$, $\cos \frac{x}{2} < 0$.
$\sin \frac{x}{2} = \sqrt{\frac{1 - \cos x}{2}} = \sqrt{\frac{1 + \frac{12}{13}}{2}} = \sqrt{\frac{25}{26}} = \frac{5}{\sqrt{26}}$.
$\cos \frac{x}{2} = -\sqrt{\frac{1 + \cos x}{2}} = -\sqrt{\frac{1 - \frac{12}{13}}{2}} = -\sqrt{\frac{1}{26}} = -\frac{1}{\sqrt{26}}$.
$\tan \frac{x}{2} = \frac{\sin \frac{x}{2}}{\cos \frac{x}{2}} = \frac{5/\sqrt{26}}{-1/\sqrt{26}} = -5$.
Answer: $\sin \frac{x}{2} = \frac{5}{\sqrt{26}}$, $\cos \frac{x}{2} = -\frac{1}{\sqrt{26}}$, $\tan \frac{x}{2} = -5$
14. If $\alpha$ and $\beta$ are different complex numbers with $|\beta| = 1$, find $\left|\frac{\beta - \alpha}{1 - \overline{\alpha}\beta}\right|$.
Solution: Since $|\beta| = 1$, $\beta \overline{\beta} = 1 \Rightarrow \overline{\beta} = \frac{1}{\beta}$.
$\left|\frac{\beta - \alpha}{1 - \overline{\alpha}\beta}\right| = \left|\frac{\beta - \alpha}{\beta\overline{\beta} - \overline{\alpha}\beta}\right|$ (multiplying numerator and denominator by $\overline{\beta}$)
$= \left|\frac{\beta - \alpha}{\beta(\overline{\beta} - \overline{\alpha})}\right| = \frac{|\beta - \alpha|}{|\beta| \cdot |\overline{\beta} - \overline{\alpha}|} = \frac{|\beta - \alpha|}{1 \cdot |\overline{\beta - \alpha}|} = 1$.
Answer: 1
15. Draw the graph of the function and write its domain and range.
$f(x) = \begin{cases} 2 - x, & \text{if } x < 0 \\ 2, & \text{if } x = 0 \\ x + 2, & \text{if } x > 0 \end{cases}$
Solution: Domain = $\mathbb{R}$ (all real numbers).
For $x < 0$, $f(x) = 2 - x \in (2, \infty)$.
For $x = 0$, $f(0) = 2$.
For $x > 0$, $f(x) = x + 2 \in (2, \infty)$.
Range = $[2, \infty)$.
Answer: Domain = $\mathbb{R}$, Range = $[2, \infty)$
16. If $(x + iy)^3 = u + iv$, show that $\frac{u}{x} + \frac{v}{y} = 4(x^2 - y^2)$.
Solution: $(x + iy)^3 = (x^3 - 3xy^2) + i(3x^2y - y^3)$.
So $u = x^3 - 3xy^2 = x(x^2 - 3y^2)$, $v = 3x^2y - y^3 = y(3x^2 - y^2)$.
$\frac{u}{x} + \frac{v}{y} = (x^2 - 3y^2) + (3x^2 - y^2) = 4x^2 - 4y^2 = 4(x^2 - y^2)$.
Answer: Hence proved.
SECTION – D (4 Marks) [1 × 4 = 4]
17. Prove that: $\sqrt{2 + \sqrt{2 + \sqrt{2 + 2\cos 8\theta}}} = 2\cos \theta$.

OR
Prove that: $\frac{\sin 3x}{\sin x} - \frac{\cos 3x}{\cos x} = 2$.
Solution (Option 1): Using $1 + \cos 2\theta = 2\cos^2 \theta$:
$2 + 2\cos 8\theta = 2(1 + \cos 8\theta) = 4\cos^2 4\theta$.
$\sqrt{2 + 2\cos 8\theta} = 2|\cos 4\theta|$.
Similarly, $\sqrt{2 + 2\cos 4\theta} = 2|\cos 2\theta|$ and $\sqrt{2 + 2\cos 2\theta} = 2|\cos \theta|$.
For suitable ranges, absolute values are positive.
LHS = $\sqrt{2 + \sqrt{2 + 2\cos 4\theta}} = \sqrt{2 + 2\cos 2\theta} = 2\cos \theta$.
Answer: Hence proved.

Solution (Option 2): $\frac{\sin 3x}{\sin x} - \frac{\cos 3x}{\cos x} = \frac{\sin 3x \cos x - \cos 3x \sin x}{\sin x \cos x}$
$= \frac{\sin(3x - x)}{\sin x \cos x} = \frac{\sin 2x}{\sin x \cos x} = \frac{2\sin x \cos x}{\sin x \cos x} = 2$.
Answer: Hence proved.
Case Study (Trigonometry) [4]

Trigonometry – from Greek ‘Trigon’ (triangle) and ‘metron’ (measure) – studies relationships between angles and sides. Degree and radian units are used. $\pi$ radian = $180^\circ$; $1^\circ = 60'$ (minutes), $1' = 60''$ (seconds); arc length $l = r\theta$.

Based on the above, answer the following questions:

(i) Convert $\frac{13}{36}$ radians into degrees, minutes and seconds. [1]
Solution: $1$ radian = $\frac{180}{\pi}^\circ$.
$\frac{13}{36}$ radians = $\frac{13}{36} \times \frac{180}{\pi}^\circ = \frac{65}{\pi}^\circ \approx 20.69^\circ$.
$20^\circ + 0.69 \times 60' = 20^\circ 41.4'$.
$41' + 0.4 \times 60'' = 41' 24''$.
Answer: $20^\circ 41' 24''$
(ii) Convert $\frac{5\pi}{12}$ into degree measure. [1]
Solution: $\frac{5\pi}{12} \times \frac{180^\circ}{\pi} = 75^\circ$.
Answer: $75^\circ$
(iii) Find the length of the arc traced by the minute hand of a clock in 10 minutes, if the radius is 10.5 cm. [2]
OR If arcs of same length in two circles subtend angles $60^\circ$ and $75^\circ$ at the centre, find the ratio of their radii.
Solution (Option 1): In 10 minutes, minute hand covers $\frac{10}{60} \times 2\pi = \frac{\pi}{3}$ radians.
Arc length $l = r\theta = 10.5 \times \frac{\pi}{3} = 3.5\pi$ cm.
Answer: $3.5\pi$ cm

Solution (Option 2): $l_1 = l_2 \Rightarrow r_1\theta_1 = r_2\theta_2$.
$\theta_1 = 60^\circ = \frac{\pi}{3}$, $\theta_2 = 75^\circ = \frac{5\pi}{12}$.
$\frac{r_1}{r_2} = \frac{\theta_2}{\theta_1} = \frac{5\pi/12}{\pi/3} = \frac{5}{4}$.
Answer: $r_1 : r_2 = 5 : 4$
