  1. Sets: Collection of well-defined objects.
    • Roster Form: A = {1, 2, 3}.
    • Set-Builder Form: A = {x : x is a natural number ≤ 3}.
  2. Types of Sets:
    • Empty Set: ∅ = {}.
    • Subset: B ⊆ A if every element of B is in A.
  3. Operations:
    • Union (A ∪ B): All elements in A or B.
    • Intersection (A ∩ B): Common elements in A and B.
  4. Venn Diagrams: Visual tool for set relationships.

Students will be able to:

  • Define sets and represent them in different forms (roster, set-builder).
  • Identify and classify types of sets (empty, finite, infinite, equal, equivalent, subsets).
  • Perform operations on sets (union, intersection, difference, complement).
  • Apply Venn diagrams to visualize set operations and solve problems.
 Guided discovery, real-world sorting activities, visual Venn diagram tools, and collaborative problem solving. Analytical Reasoning, Classification Skills, Logical Deduction, Critical Thinking. Database query logic (SQL JOINs), probability sample spaces, and circuit design logic.

Core Concepts:

  • Cartesian Products of Sets (Definition, Properties, Examples)
  • Relations (Definition, Domain, Range, Codomain, Representation)
  • Functions (Definition, Domain, Range, Types of Functions)
  • Algebra of Real Functions (Addition, Subtraction, Multiplication, Division)

Key Definitions:

  • Ordered Pair: A pair of elements grouped in a specific order
  • Cartesian Product: P × Q = {(p,q) : p ∈ P, q ∈ Q}
  • Relation: A subset of the Cartesian product
  • Function: A relation where every element of set A has one and only one image in set B

Function Types:

  • Identity Function: f(x) = x
  • Constant Function: f(x) = c
  • Polynomial Function: f(x) = a₀ + a₁x + ... + aₙxⁿ
  • Rational Function: f(x)/g(x) where g(x) ≠ 0
  • Modulus Function: f(x) = |x|
  • Signum Function
  • Greatest Integer Function
  • Students will understand and compute Cartesian products of sets
  • Students will differentiate between relations and functions
  • Students will determine domain, range and codomain of relations and functions
  • Students will represent relations through arrow diagrams, roster form and set-builder form
  • Students will identify different types of functions and their properties
  • Students will perform algebraic operations on real functions
  • Students will solve problems involving relations and functions

Periods 1-2: Introduction

Lecture with real-life examples, group activity for Cartesian products

Periods 3-4: Relations

Visual representations (arrow diagrams), problem-solving in pairs

Periods 5-7: Functions

Interactive graphing activities, function identification exercises

Periods 8-10: Function Types

Graph plotting lab, real-world applications, case studies

Period 11: Algebra of Functions

Step-by-step demonstration, practice worksheets

Period 12: Review

Concept mapping, Q&A session, assessment


Teaching Methods: Interactive lectures, group activities, visual demonstrations (graph plotting), problem-solving sessions, real-world applications, digital tools (graphing software)
  • Critical Thinking: Analyzing relations and functions for problem-solving
  • Logical Reasoning: Understanding function properties and behavior
  • Digital Literacy: Using graphing software/tools for visualization
  • Collaboration: Group activities for Cartesian products and relations
  • Precision: Attention to detail in mathematical definitions and notations
  • Real-world Application: Understanding how functions model real phenomena
  • Relations in database systems (mapping elements between sets)
  • Functions in physics: Position-time, velocity-time relationships
  • Temperature conversion as a function (Celsius to Fahrenheit)
  • Economic applications: Demand-supply functions
  • Computer science: Functions in programming and algorithms
  • Graphing real-world data to identify functional relationships
  • Practical exercise: License plate coding example from textbook
अन्य विषयों के साथ एकीकरण / Integration with other subjects:
  • Physics: Motion equations as functions, wave functions
  • Computer Science: Functions in programming, relational databases
  • Economics: Cost, revenue and profit functions
  • Geography: Coordinate systems (Cartesian products in mapping)
  • Chemistry: Reaction rates as functions of concentration

Extension / Real life applications
  1. Angle Measurement
    • Radians: 180° = π radians
    • Arc length: l = rθ (θ in radians)
    • Conversions: Degree ⇄ Radian
  2. Trigonometric Functions
    • Unit circle definitions: sin θ = y/r, cos θ = x/r
    • Signs in quadrants: CAST rule
    • Fundamental identity: sin²θ + cos²θ = 1
  3. Sum/Difference Formulas
    • sin(x±y) = sin x cos y ± cos x sin y
    • cos(x±y) = cos x cos y ∓ sin x sin y
    • tan(x±y) = (tan x ± tan y)/(1 ∓ tan x tan y)
  4. Multiple Angles
    • Double angle: sin 2x = 2 sin x cos x, cos 2x = cos²x - sin²x
    • Triple angle: sin 3x = 3 sin x - 4 sin³x
    • Half angle: sin(x/2) = ±√[(1 - cos x)/2]
  5. Graphs
    • Periodicity: sin(x + 2π) = sin x
    • Key features: Amplitude, period, phase shift
    • Transformations: y = a sin(bx + c) + d

Students will be able to:

  • Convert between degree and radian measures of angles
  • Define trigonometric functions using unit circles and right triangles
  • Apply trigonometric identities to simplify expressions
  • Solve trigonometric equations using algebraic and graphical methods
  • Sketch and analyze graphs of trigonometric functions
  • Solve real-world problems involving periodic phenomena
 Guided discovery, real-world sorting activities, visual Venn diagram tools, and collaborative problem solving. Analytical Reasoning, Classification Skills, Logical Deduction, Critical Thinking. Database query logic (SQL JOINs), probability sample spaces, and circuit design logic.
